# ㄱ할게 GOE 수정 지시서 — 상용구·작년 이맘때를 단체 쪽지 중심으로

- 작성: 2026-11-17 (소스가 없는 PC에서 쓴 지시서. 소스가 있는 PC에서 이 문서대로 고친다)
- 대상: ㄱ할게 GOE 1.7 (`moonsugugu/goe-viewer-brity`, 실행 파일 `ㄱ할게GOE.exe`, Brity 연결 `--brity`)
- 다음 버전: **1.8**

## 1. 왜 바꾸나

상용구와 작년 이맘때에 한 사람에게 보낸 개인 쪽지까지 다 섞여 나와서, 다시 쓸 만한 글이 묻힌다.
**5명 이상에게 간 단체 쪽지**(공지, 안내, 협조 요청, 행사 일정)가 해마다 다시 쓰는 글이므로 그것만 기본으로 보여 준다.

실제 기록(`문서\백업_Exports\백업_이문수_20261116_123108`)으로 센 숫자:

| 구분 | 전체 | 받는 사람 5명 이상 | 3명 이상 | 10명 이상 |
|---|---:|---:|---:|---:|
| 보낸쪽지 | 1,140 | **56** | 76 | 47 |
| 받은쪽지 | 2,218 | **1,014** | 1,068 | 797 |

보낸 쪽지 1,140건 중 1,058건이 한 사람에게 보낸 것이라, 지금 상용구는 대부분 개인 답장으로 채워진다.

## 2. 받는 사람 수 세기 (공통 함수)

CSV 열: `일시, 구분, 보낸사람, 받는사람, 제목, 내용, 첨부파일`. `구분`은 `받은쪽지` / `보낸쪽지`.

`받는사람` 칸은 이름이 쉼표로 이어진 문자열이다. 아래처럼 센다.

```js
// 받는 사람 수. 화면용 "외 N명" 표기가 섞여 들어와도 맞게 센다.
function recipientCount(receiver) {
  const s = String(receiver || '');
  const names = new Set(s.split(/[,;\n]/).map(x => x.trim()).filter(Boolean));
  const m = s.match(/외\s*(\d+)\s*명?/);
  return names.size + (m ? Number(m[1]) : 0);
}
const isGroup = (msg, min) => recipientCount(msg.receiver) >= min;
```

- 이름이 같은 사람이 두 번 들어가 있으면 한 명으로 센다.
- 현재 기록에는 `외 N` 표기가 없다(0건). 혹시 모를 형식을 위해 넣어 둔 것이다.
- 받는 사람 칸이 비어 있으면 0명이다. 단체 쪽지로 보지 않는다.
- 프로그램 창과 Brity 탭(`#year`, `#helper`)이 **같은 프런트 코드**를 쓰므로, 이 함수는 프런트 공통 모듈에 둔다. Brity 탭은 `load_latest_csv`로 CSV 원문을 받아 프런트에서 나누므로, 백엔드는 고칠 필요가 없다.

## 3. 기준 인원 설정

- 설정 이름: `groupMin`. 기본값 **5**, 고를 수 있는 값은 2~30.
- 설정 창에 한 줄 추가: "단체 쪽지 기준 — 받는 사람 [5]명 이상".
- 기존 설정을 저장하는 곳(프로그램과 Brity 탭이 함께 보는 곳)에 같이 저장한다. 두 화면의 값이 달라지지 않게 한다.

## 4. 상용구 (기록 묻기 탭 · 프로그램의 기록 묻기)

현재: 내가 보낸 쪽지를 제목별로 묶어 보여 준다. 정렬은 고정(★) 먼저, 많이 보낸 순, 최근 순이고 최대 60개를 보여 준다.

바꿀 것:
1. 묶기 전에 **`isGroup(msg, groupMin)`인 보낸 쪽지만** 남긴다.
2. 검색칸 옆에 스위치 **[개인 쪽지도 보기]**를 둔다. 기본은 꺼짐이고, 켜면 지금처럼 전부 보여 준다. 스위치 상태는 기억한다.
3. **★ 고정한 상용구는 기준과 상관없이 늘 보여 준다.** 이미 고정해 둔 개인 쪽지가 사라지면 안 된다.
4. 안내 문구(sub)를 바꾼다: "내가 **여러 사람에게** 보낸 쪽지에서 다시 쓸 만한 글…".
5. 목록 각 줄에 받는 사람 수를 작게 표시한다(예: `54명`).
6. 결과가 없을 때 문구를 바꾼다: "받는 사람이 5명 이상인 보낸 쪽지가 없습니다." 그 아래에 [개인 쪽지도 보기] 단추를 둔다.

## 5. 작년 이맘때 (작년 이맘때 탭 · 프로그램의 작년 이맘때)

현재: 지난해 이번 주·다음 주·2주 뒤에 주고받은 쪽지를 날짜별로 보여 준다. 해당 쪽지가 있으면 켤 때 위쪽에 알림을 띄운다.

바꿀 것:
1. 받은 쪽지와 보낸 쪽지 모두 **`isGroup(msg, groupMin)`인 것만** 기본으로 보여 준다.
2. 같은 **[개인 쪽지도 보기]** 스위치를 둔다. 기본은 꺼짐이고, 상용구와 따로 기억한다.
3. **켤 때 뜨는 알림도 단체 쪽지만 센다.** 개인 쪽지만 있는 주에는 알림을 띄우지 않는다.
4. 날짜 묶음 머리에 "단체 쪽지 N건 · 개인 M건 숨김"처럼 숨긴 수를 보여 준다. 숨긴 게 0이면 생략한다.
5. **우리 학교 1년**은 바꾸지 않는다. 달마다 쪽지 수는 지금처럼 전체를 센다.
   - '해마다 돌아오는 일'을 단체 쪽지로만 뽑을지는 이문수 선생님께 확인한 뒤 정한다.

## 6. 바꾸지 않는 것

- 지난 기록에 묻기(AI)가 근거 쪽지를 고르는 방식
- AI로 정리, 할 일 달력
- 기본 쪽지 목록과 검색
- CSV 추출 형식. 이전에 추출한 CSV도 그대로 읽혀야 한다.
- 모든 계산은 이 PC 안에서만 한다. AI나 외부로 보내는 것은 없다.

## 7. 확인할 것 (테스트)

`백업_이문수_20261116_123108` 기록으로 확인한다. 이 기록은 **2026-02-11 ~ 2026-11-16** 범위다.
작년(2025) 기록이 없으므로 작년 이맘때는 날짜를 바꿔 넣어 확인한다. 예를 들어 오늘을 2027-03-03으로 두면 2026-03 기록이 잡힌다.

- [ ] `recipientCount` 단위 테스트
  - `"가,나,다,라,마"` → 5
  - `"가, 가 ,나"` → 2
  - `""` → 0
  - `"가 외 53명"` → 54
- [ ] 상용구 기본 화면의 바탕이 보낸 쪽지 **56건**(기준 5)이다. 기준 3이면 76건, 10이면 47건이다. 화면에는 제목별로 묶은 수가 보이므로 묶기 전 개수로 확인한다.
- [ ] 작년 이맘때에서 받은 단체 쪽지 대상은 **1,014건**, 보낸 단체 쪽지 대상은 **56건**이다.
- [ ] [개인 쪽지도 보기]를 켜면 1.7과 같은 결과가 나온다.
- [ ] ★ 고정해 둔 개인 쪽지 상용구가 기본 화면에서도 보인다.
- [ ] 기준 인원을 바꾸면 프로그램 창과 Brity 탭 양쪽에 반영된다. Brity 탭은 새로고침 뒤 반영되어도 된다.
- [ ] **프로그램 창을 닫고 `--brity`만 켜진 상태**에서 `#year`, `#helper` 탭이 정상으로 열린다(2026-11-17에 1.7로 이 상태 정상 동작 확인함).
- [ ] 개인 쪽지만 있는 주에는 켤 때 작년 이맘때 알림이 뜨지 않는다.

## 9. [꼭 고칠 것] 재부팅하면 Brity 연결이 자동으로 안 켜짐 (2026-11-18 추가)

**증상**: PC를 켜면 Brity의 세 탭(GOE 보관함·작년·기록묻기)에 모두 '사이트가 정상적으로 열리지 않을 수 있습니다'가 뜬다. 프로그램에서 다시 켜야 보인다.

**원인**: Windows 이벤트 로그(`Microsoft-Windows-Shell-Core/Operational`, 9707·9708)를 보면 11/17·11/18 두 번 모두 결과가 같다.
- `'ㄱ할게GOE.exe --brity' 명령(PID 0)의 실행을 마쳤습니다`로 끝났다. 시작에 실패한 것이다.
- 같은 때 실행된 다른 시작 프로그램은 모두 PID를 받아 정상으로 켜졌다.
- 앱이 등록한 Run 값은 `C:\Users\admin\AppData\Local\Programs\ㄱ할게GOE\ㄱ할게GOE.exe --brity`다. 경로에 따옴표가 없고 한글이 들어 있다.
- 같은 명령을 직접 실행하면 잘 켜진다. 탐색기의 시작 프로그램 실행만 실패한다.

**이 PC에 임시로 해 둔 것**:
- Run 값 `ㄱ할게GOE_Brity`를 `"C:\Windows\System32\wscript.exe" "C:\Users\admin\AppData\Local\goe-brity-start.vbs"`로 바꿨다.
- vbs(UTF-16)가 한글 경로의 exe를 `--brity`로 창 없이 실행한다.
- 이 상태에서 앱의 **켜기**를 다시 누르면 원래 값으로 되돌아가 문제가 다시 생길 수 있다.

**앱에서 고칠 것**:
1. Brity 켜기에서 Run 값을 쓸 때 **경로를 따옴표로 감싸고**, 한글이 없는 경로를 거치게 한다. 방법은 다음 중 하나다.
   - 한글이 없는 경로에 시작용 파일을 둔다. 예: `%LOCALAPPDATA%\goe-brity\start.vbs`
   - 작업 스케줄러의 로그온 작업(지연 30초)으로 바꾼다.
2. 끄기와 앱 제거는 바뀐 방식(vbs 파일이나 예약 작업)까지 지운다. 이 PC의 `goe-brity-start.vbs`도 지운다.
3. 앞으로 설치 폴더 이름을 `ㄱ할게GOE` 대신 ASCII(`GoeViewer`)로 바꾸는 것도 검토한다. 기존 설치는 옮겨 준다.
4. 테스트: 켜기 → **재부팅** → 로그인만 하고 아무것도 누르지 않은 채 1분 뒤 Brity 탭 새로고침 → 기록이 보인다.
   - 이벤트 9708에 PID가 0이 아닌 값으로 남는지도 본다.
