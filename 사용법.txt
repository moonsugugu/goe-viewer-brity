ㄱ할게 GOE 사용법 (버전 1.4)
=====================================

■ 이게 뭔가요?
GOE메신저의 대화와 쪽지를 메신저 없이 열어 보고, 엑셀(CSV)로 뽑는 프로그램입니다.
모든 처리가 이 PC 안에서만 이루어지며, 기록(쪽지·대화·이름)은 PC 밖으로 나가지 않습니다.
인터넷으로는 새 버전 확인과, 이용자 수를 세는 익명 신호(임의 번호·버전·날짜)만 보냅니다.
익명 신호는 [설정]에서 체크를 끄면 보내지 않습니다.

■ 시작하기
1) 'ㄱ할게 GOE'를 실행합니다.
2) 선생님 이름을 입력하고 버튼을 누릅니다.
   - [처음 시작하기]      : 이 PC의 GOE메신저 기록에서 그 이름이 들어간 대화·쪽지를 찾아
                            보여 주고, '문서\백업_Exports'에 CSV로 저장합니다.
                            처음 한 번은 이 버튼을 누르세요.
   - [추출 없이 시작하기] : 전에 저장해 둔 CSV를 바로 엽니다. 두 번째부터는 이쪽이 빠릅니다.
   ※ 이름은 두 글자 이상 입력해야 합니다. 한 번 쓴 이름은 다음에 자동으로 채워집니다.

■ 찾기
- 위쪽 파란 띠에서 수신함·발신함·대화함을 눌러 켜고 끕니다. (처음에는 쪽지만 켜져 있습니다)
- 위 검색창에 낱말을 넣으면 제목·내용·사람·파일명에서 찾습니다.
- [상세검색]을 열면 기간·제목·발신인·수신인·파일명·내용으로 좁힐 수 있습니다.
- [날짜별]을 누르면 날짜마다 몇 건인지 보이고, 날짜를 누르면 그날 것만 봅니다.
- 줄을 누르면 쪽지 전문이나 대화방이 오른쪽에 열립니다.
- 목록이 길면 맨 아래 [더보기 (+200개)]로 200개씩 더 봅니다.
- [엑셀(CSV)로 내보내기]는 지금 보이는 검색 결과를 CSV 파일 하나로 저장합니다.

■ 즐겨찾기와 분류함
- 별을 누르면 즐겨찾기에 들어갑니다. 위쪽 파란 띠의 '즐겨찾기만'으로 모아 봅니다.
- 줄 앞의 칸을 체크하면 위에 막대가 나타납니다. 거기서 분류함에 담거나 새 분류함을 만듭니다.
- 검색창 아래 '분류함' 줄에서 이름을 누르면 그 안에 담긴 것만 봅니다.
- 즐겨찾기와 분류함은 이 PC에 저장되어 다음에 켜도 남아 있습니다.

■ 첨부파일 열기
- 첨부파일 이름을 누르면 이 PC에서 그 파일을 찾아 엽니다.
  · 받은 파일: '문서\GOE메신저\Message 받은 파일'의 날짜 폴더 속까지 찾습니다.
  · 보낸 파일: 바탕 화면·다운로드·문서에서 찾습니다.
- 받은 파일을 다른 폴더에 두었다면 [받은 파일 폴더]에서 그 폴더를 정합니다.
- 메신저로 내려받지 않은 파일은 PC에 없어서 열리지 않습니다.

■ 교실(PC)을 옮길 때
GOE메신저 기록은 지금 쓰는 PC에만 있습니다. 옮길 것은 두 가지입니다.
  · 기록(쪽지·대화)        : CSV 파일로 담습니다.
  · 받은 파일(첨부파일)    : '문서\GOE메신저' 폴더를 통째로 담습니다.
두 번에 나눠서 합니다. 창에 나오는 순서대로 누르면 됩니다.

① 예전 PC에서 — USB에 담기
1) 이동식 디스크(USB)를 꽂고 [교실 옮기기 전 USB에 저장!]을 누릅니다.
2) 담을 곳(USB)을 고르고, 이름과 받은 파일 폴더를 확인한 뒤 [USB에 담기]를 누릅니다.
   → USB에 이렇게 들어갑니다.
     ㄱ할게GOE_백업
       ├ 백업_이름_날짜            기록 (쪽지·대화 CSV)
       ├ 받은 파일                 첨부파일
       └ 새 교실에서 여는 방법.txt  안내문
   받은 파일이 많으면 시간이 걸립니다. 끝날 때까지 창과 USB를 그대로 두세요.

② 새 PC에서 — USB에서 꺼내기
1) 새 PC에 ㄱ할게 GOE를 설치하고, USB를 꽂은 뒤 [새 교실에서 USB 불러오기]를 누릅니다.
2) USB를 고르고 이름을 입력한 뒤 [기록 넣기]를 누릅니다.
   → 기록이 새 PC의 '문서\백업_Exports'에 들어갑니다.
3) [받은 파일 넣기]를 누릅니다.
   → 받은 파일이 새 PC의 '문서\GOE메신저'에 들어갑니다. 다른 곳에 두려면 [다른 폴더로 바꾸기]로 고릅니다.
4) [기록 열기]를 누릅니다. 이제 USB는 뽑아도 됩니다.
   다음부터는 이름을 입력하고 [추출 없이 시작하기]를 누르면 바로 열립니다.
※ 받은 파일을 나중에 다른 폴더로 옮겼다면 [받은 파일 폴더]에서 그 폴더를 다시 정하세요.

■ Brity 메신저 안에서 보기
Brity 워크스페이스에 탭을 하나 만들어 두면, 이 프로그램을 켜지 않아도 Brity 안에서 기록을 봅니다.
먼저 [처음 시작하기]로 기록을 한 번 저장해 둔 뒤에 하세요.
1) [Brity 탭에서 보기]를 누르고 [켜기]를 누릅니다.
   → 처음 켤 때 Windows가 인증서를 설치할지 묻습니다. [예]를 누르세요.
     (Brity가 이 PC의 기록을 열 때만 쓰는 인증서입니다.)
2) [주소 복사]를 누릅니다.
3) Brity에 탭을 만듭니다. (프로그램의 같은 창에 순서 그림이 있습니다)
   ① Brity에서 나만 들어 있는 워크스페이스의 채널을 엽니다.
      없으면 [새 워크스페이스 만들기]로 하나 만듭니다.
   ② 채널 위쪽의 '메시지 · 공지 · 파일 · 링크' 탭 줄 끝에 있는 [+]를 누릅니다.
      마우스를 올리면 '웹사이트 탭을 추가하여 팀 멤버와 협업해보세요!'라고 나오는 단추입니다.
      창이 좁으면 탭 줄의 펼침 목록 안에 '웹사이트 탭 추가'로 들어 있습니다.
   ③ '웹사이트 탭 추가' 창의 '탭 이름'에  ㄱ할게 GOE  라고 적습니다. (10자까지)
   ④ 'URL 주소' 칸의 https:// 뒤를 누르고 Ctrl+V로 붙여넣습니다. 주소가 index.html로 끝나면 맞습니다.
   ⑤ [추가]를 누릅니다. '탭이 추가되었습니다.'가 뜨고 탭 줄에 ㄱ할게 GOE가 생깁니다.
   잘 안 될 때
   · 빨간 글씨 '형식이 유효하지 않습니다.' → 주소가 index.html로 끝나는지 보고, [주소 복사]를 다시 눌러 붙여넣습니다.
     https://가 두 번 들어가도 이렇게 나옵니다.
   · 기록 대신 '아래의 경우 사이트가 정상적으로 열리지 않을 수 있습니다.'가 보임
     → 이 PC의 Brity 연결이 꺼져 있습니다. 프로그램에서 '켜져 있습니다'인지 확인하고 Brity에서 [새로고침]을 누릅니다.
   · 기록 위쪽의 '사이트가 정상적으로 열리지 않는 경우, 여기를 클릭하십시오.'는 Brity가 늘 보여 주는 안내입니다.
     오른쪽 ×로 닫으면 됩니다.
   · 주소를 고치거나 탭을 지우려면 ㄱ할게 GOE 탭을 마우스 오른쪽 단추로 눌러 [편집]이나 [삭제]를 고릅니다.
   · 웹사이트 탭은 PC의 Brity에서만 열립니다.
- 켜 두면 PC를 켤 때 Brity 연결이 창 없이 함께 시작됩니다.
- 탭에서는 보기·검색·첨부파일 열기만 됩니다. '추출 없이 시작하기'와 같은 기록을 보여 주므로,
  GOE메신저 기록이 더 쌓였으면 프로그램에서 [처음 시작하기]를 다시 누르세요.
- 기록은 이 PC 안에서만 오가며 Brity 서버나 인터넷으로 나가지 않습니다.
  주소는 이 PC에서만 열리지만, 여럿이 쓰는 워크스페이스에는 넣지 마세요.
- 그만 쓰려면 같은 창에서 [끄기]를 누릅니다. 자동 시작과 인증서를 지웁니다(Windows가 한 번 묻습니다).
- 즐겨찾기와 분류함은 프로그램과 Brity 탭이 따로 기억합니다.

■ 그 밖의 도구 (왼쪽 QUICK MENU)
- [받은 파일 폴더] : 첨부파일 이름을 눌렀을 때 찾을 폴더를 보거나 바꿉니다.
- [CSV 직접 추출] : 기간과 항목(대화/쪽지)을 정해서 CSV로 저장합니다.
- [CSV 폴더 열기] : 추출된 CSV가 모이는 '문서\백업_Exports'를 엽니다.
                    필요 없어진 CSV는 여기서 직접 지우면 됩니다.
- [설정]          : 버전, 업데이트 확인, 받은 파일 폴더, 앱 제거가 있습니다.
- 프로그램이 켜져 있는 동안 작업 표시줄 오른쪽(알림 영역)에 ㄱ할게 GOE 아이콘이 있습니다.
  마우스 오른쪽 단추로 누르면 열기·설정·업데이트 확인·종료 메뉴가 나옵니다.

■ 업데이트
- 프로그램을 켤 때(그리고 켜 둔 동안 6시간마다) 새 버전이 있는지 확인합니다.
  새 버전이 있으면 오른쪽 아래에 알림이 뜹니다. [자세히] → [설치 파일 받기]를 누르세요.
  깃허브에 최신 버전 번호만 묻고, 기록은 보내지 않습니다.
- 받은 설치 파일(GoeViewerSetup.exe)을 실행하면 같은 자리에 덮어써서 업데이트됩니다.
  켜져 있는 프로그램은 자동으로 닫힙니다. 기억된 이름, 즐겨찾기, 분류함, CSV, 받은 파일은 그대로 남습니다.
- 같은 버전의 설치 파일을 다시 실행하면 [다시 설치]와 [삭제]를, 옛 버전이면 [업데이트]와 [삭제]를 고를 수 있습니다.
  더 새 버전이 이미 깔려 있으면 옛 설치 파일로 덮어쓰지 않습니다.
- 1.4 이하에는 업데이트 확인이 없습니다. 이번 한 번만 새 설치 파일을 직접 받아 실행하세요.
  (무설치판은 새 GoeViewer.exe로 바꿔 쓰면 됩니다.)

■ 지우기
- 프로그램의 [설정 > 앱 제거], Windows 설정 > 앱 > 설치된 앱, 제어판 > 프로그램 제거 중 어디서든 지울 수 있습니다.
- 프로그램·바로가기와 Brity 연결(자동 실행·인증서)을 지웁니다. 추출한 CSV와 받은 파일은 남습니다.

■ 실행 요구사항
- Windows 10/11 64비트 + Microsoft Edge WebView2 런타임 (보통 이미 있습니다)
- [처음 시작하기]는 이 PC에서 GOE메신저를 쓴 적이 있어야 됩니다.
